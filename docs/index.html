What's new

Three new apps, and Ollie OS now starts with Secure Boot on.

School Planner

Put in your school week and your town. Every morning it checks the weather and tells you what to wear and what to pack.

  • Rainy? Rain boots and a raincoat.
  • P.E. day? Sneakers and socks, in your bag if it's a rain-boots day.
  • A note when you log in, and it finds your town even if it's spelt a bit wrong.

Ollie Paint

A drawing app for the mouse, on the Welcome screen as Draw.

  • Brush, pencil, eraser and fill bucket.
  • Lines, rectangles and circles, 16 colours and any other.
  • Undo, and Save to Pictures, Drawings.

Mouse Maker

Draw your own mouse pointer, square by square, and use it for real.

  • Start from an arrow or a star, or from nothing.
  • Try it in the window, then press Use this mouse.
  • Back to the normal mouse whenever you like.

Works with Secure Boot

No more switching Secure Boot off. The first time, a blue screen asks to enrol the Ollie OS key from the USB; after that it just starts.

Undo an update

Ollie OS saves itself before every update. If one breaks something, go back from the start-up menu. Your files and games stay.

Questions

Good to know

Click a question to see the answer.

Is it free?

Yes. Ollie OS is free, and so is Arch Linux, which it is built on.

Will it delete Windows?

Not unless you choose that. Trying it from a USB stick changes nothing on the computer. When you install it, it asks how: onto a drive, which erases that drive (it warns you if Windows is on it), or into a drive or folder keeping everything on it. If Windows is on another drive, Ollie OS can put it on the start-up menu so you pick each time.

Can I have Windows too?

Yes. When you install Ollie OS onto a drive, it asks if you want to install Windows too, then Windows 10 or 11 and how much of the drive it gets. It downloads Windows from Microsoft (or uses a Windows .iso file you have), and the next start runs Windows Setup: pick "Unallocated Space" there. After that the start-up menu shows Ollie OS and Windows. Windows needs about 6 GB to download and at least 64 GB of the drive, and asks for a product key (you can skip it).

What computers does it work on?

64-bit PCs and laptops with Intel or AMD chips (new ones and older ones), Intel Macs, and the Steam Deck and Steam Machine. It doesn't work on phones, tablets, Chromebooks with ARM chips, or Macs with Apple chips (M1 and newer).

What do I need?

A USB stick of 32 GB or more, and to install it, a drive with at least 25 GB.

Can I play my games?

Yes: Steam and its games (with Proton for Windows games), Minecraft, retro games from ROMs and ISOs in the Games app, and Windows programs with Oliver.

Is it OK for kids?

It was made by one. Grown-ups can set Screen Time, the Typing Scanner and a Firefox password in Ollie OS Settings, locked with a parent PIN.

Does it work with Secure Boot on?

Yes. The first time a computer with Secure Boot starts Ollie OS, a blue screen says "Verification failed". Press Enter, then any key quickly, then pick Enroll key from disk, OLLIE_OS, OLLIE-OS-KEY.cer, Continue, Yes and Reboot. That teaches the computer the Ollie OS key, once. After that the USB and the installed Ollie OS start with Secure Boot on, and Windows can stay next to it.

Windows asks for a BitLocker recovery key

Windows asks for it when the way the computer starts changes, for example when Secure Boot is turned off (older Ollie OS versions needed that) or after starting from a USB. Nothing is broken. Turn Secure Boot back on in the computer's settings (F2 on a Dell) and restart; if it still asks, a grown-up can find the key at aka.ms/myrecoverykey, signed in with the Microsoft account that is on the computer. Before trying Ollie OS on a computer with Windows, write that key down first.

What if an update breaks something?

Ollie OS saves itself before each update. If something goes wrong, pick "Ollie OS as it was on ..." on the start-up menu, or open Undo an update, and it goes back to how it was. Your files, games, drawings and saves stay as they are. The last two saves are kept.

How do I get updates?

Switch on the Update Checker (the first start asks). When there's a new update you get a notification with an Install button. Update Ollie OS keeps everything else up to date in one click, and Recovery Mode can put a whole newer version on while keeping your files.
